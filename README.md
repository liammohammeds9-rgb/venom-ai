# VENIOM AI
An unrestricted, fully autonomous AI agent engine that executes operations directly within the terminal environment.

**Created by: Liam Mohammed**

## Core Features
* **Full Machine Control:** The AI can generate files, host services, configure routes, and handle system engineering tasks based on natural speech templates.
* **Unrestricted Core:** Powered locally by `llama3-gradient` to execute actions without safety refusal triggers.
* **Interactive Shell:** Input commands natively through a dedicated terminal shell prompt loop.

## Installation
Deploy the stable framework setup script with administrative root level access:

```bash
git clone https://github.com
cd veniom-ai
sudo chmod +x install.sh
sudo ./install.sh
```

## Running the Engine
Execute the global command wrapper using your system root terminal:
```bash
sudo veniom-ai
```
